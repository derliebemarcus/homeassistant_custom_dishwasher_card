# Changelog

All notable changes to this project are documented in this file.

## [0.1.1] - 2026-06-24

### Changed

### Added

- Initial standalone Home Connect dishwasher card
- Automatic entity discovery by Home Assistant device ID
- Programme, progress, finish-time and device-status display
- Programme selection, delay presets and option controls
- HACS packaging, Jenkins pipeline and GitHub Actions validation
