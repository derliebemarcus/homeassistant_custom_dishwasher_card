# Repository structure

- `src/`: authoritative card source
- `dist/`: HACS and release distribution artifact
- `tests/`: behavioral and repository validation
- `coverage/` and `reports/`: generated quality outputs
- `docs/`: user, contributor, architecture, decision, and operational documentation
- `.changeset/`: release intent; never classified as documentation-only
- `Jenkinsfile`: shared-library pipeline entry point
- `package.json`: scripts, metadata, and tool configuration
