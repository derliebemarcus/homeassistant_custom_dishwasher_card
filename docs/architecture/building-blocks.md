# Building blocks

## Configuration normalization

Validates card configuration and resolves device-based or explicit entity mappings.

## Entity discovery

Finds Home Connect entities associated with the configured Home Assistant device.

## View model

Normalizes entity states, programme metadata, progress, finish time, and capabilities.

## Renderer and actions

Builds the responsive card UI and invokes Home Assistant services for supported user
actions.

## Build and release tooling

Tests source behavior, generates the distribution artifact, and publishes tagged assets.
