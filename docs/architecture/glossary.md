# Glossary

| Term | Meaning |
| --- | --- |
| Card | A custom Lovelace dashboard component |
| Device discovery | Resolving entities from a Home Assistant device ID |
| Distribution artifact | The built JavaScript file below `dist/` |
| HACS | Home Assistant Community Store |
| Home Connect | Integration exposing supported household appliances |
| Programme | A dishwasher wash cycle exposed by Home Connect |
