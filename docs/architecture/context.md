# System context

A Home Assistant user configures the card for a Home Connect dishwasher. The card runs
inside the Home Assistant frontend, reads appliance entities, and invokes Home Assistant
services for supported controls.

## External systems

- Home Assistant frontend and Lovelace dashboard runtime
- Home Assistant entity registry and service API
- Home Connect integration and cloud-backed appliance entities
- HACS or GitHub Releases for distribution
- Jenkins and GitHub for validation and release automation
